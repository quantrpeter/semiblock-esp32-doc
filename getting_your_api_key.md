# Getting Your API Key

To activate the SemiBlock ESP32 extension and access its cloud compilation and design features, you must first obtain a valid API key from the official SemiBlock website.

## Prerequisites

* A registered SemiBlock account.
* Both **SemiBlock ESP32** and **SemiBlock VSCode Extension** installed in Visual Studio Code (see [Initial Setup in Visual Studio Code](./initial_setup_in_vscode.md)).

## Step-by-Step Guide

1. **Visit the Official Portal**
   Open your web browser and navigate to the official SemiBlock build portal:  
   [https://build.semiblock.ai](https://build.semiblock.ai)

2. **Sign In to Your Account**
   Log in using your SemiBlock credentials. If you do not have an account yet, follow the on-screen instructions to register.

3. **Locate Your API Key**
   Once signed in, navigate to your **Account Dashboard** or **API Settings** section on the portal.

4. **Generate or Copy the Key**
   * If you already have an active key, click the **Copy** button next to your API key to copy it to your clipboard.
   * If no key is listed, click **Generate API Key** to create a new one, then copy the generated string.

> **Important:** Treat your API key like a password. Do not share it publicly or commit it to public code repositories.
